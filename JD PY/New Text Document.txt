1. File and Directory Operations

os.chdir(path) – Change current working directory.
os.getcwd() – Get current working directory.
os.listdir(path='.') – List directory contents.
os.mkdir(path, mode=0o777) – Create a directory.
os.makedirs(path, exist_ok=False) – Create directories recursively.
os.remove(path) – Remove a file.
os.rmdir(path) – Remove a directory.
os.removedirs(path) – Remove directories recursively.
os.rename(src, dst) – Rename a file or directory.
os.replace(src, dst) – Rename, overwriting if needed.
os.stat(path) – Get file/directory status.
os.scandir(path='.') – Iterator for directory entries.
os.walk(top, topdown=True, onerror=None, followlinks=False) – Generate directory tree.


2. Path and File Info

os.path.abspath(path) – Absolute path.
os.path.basename(path) – File name from path.
os.path.dirname(path) – Directory name from path.
os.path.exists(path) – Check if path exists.
os.path.isfile(path) – Check if path is a file.
os.path.isdir(path) – Check if path is a directory.
os.path.join(path, *paths) – Join paths.
os.path.split(path) – Split into (head, tail).
os.path.splitext(path) – Split extension.
os.path.getsize(path) – File size.
os.path.getmtime(path) – Last modification time.


3. Environment Variables

os.environ – Mapping of environment variables.
os.getenv(key, default=None) – Get environment variable.
os.putenv(key, value) – Set environment variable.
os.unsetenv(key) – Remove environment variable.


4. Process Management

os.system(command) – Run shell command.
os.popen(command) – Open pipe to/from command.
os.execv(path, args) – Execute program.
os.execvp(file, args) – Execute program (search PATH).
os.fork() – Fork process (Unix only).
os.kill(pid, sig) – Send signal to process.
os.getpid() – Get current process ID.
os.getppid() – Get parent process ID.


5. File Descriptor Operations

os.open(path, flags, mode=0o777) – Low-level open.
os.read(fd, n) – Read from file descriptor.
os.write(fd, str) – Write to file descriptor.
os.close(fd) – Close file descriptor.
os.dup(fd) – Duplicate file descriptor.
os.dup2(fd, fd2) – Duplicate to another descriptor.


6. Permissions & Ownership

os.chmod(path, mode) – Change permissions.
os.chown(path, uid, gid) – Change owner/group.
os.umask(mask) – Set file creation mask.
os.access(path, mode) – Check access permissions.


7. Miscellaneous

os.cpu_count() – Number of CPUs.
os.getlogin() – Name of logged-in user.
os.urandom(n) – Random bytes.
os.sep – Path separator ('/' or '\\').
os.linesep – Line separator.
os.name – OS name ('posix', 'nt', etc.).
os.pathsep – Path separator (':' or ';').
